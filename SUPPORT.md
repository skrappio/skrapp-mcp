# Support

| You need | Go to |
| --- | --- |
| Help using Skrapp or the MCP connector | [Help center](https://support.skrapp.io/hc/en-us) or <support@skrapp.io> |
| Setup steps for your client | <https://skrapp.io/mcp> |
| Tool reference | <https://skrapp.io/api#mcp> |
| A mistake in this repository's docs or examples | [Open an issue](https://github.com/skrappio/skrapp-mcp/issues/new/choose) |
| To report a vulnerability | [SECURITY.md](SECURITY.md), never a public issue |
| Billing, credits or account questions | <support@skrapp.io> |

When you write to support, include the client you use, the tool you called and the time of the call (UTC). Remove API keys, tokens and personal data first.

Privacy policy: <https://skrapp.io/privacy>. Terms: <https://skrapp.io/terms>.
